# Energy Combinator 2.1: modular development branch

Source baseline: `main` version 1.2.14, commit `cd1ed627a6f5ba4e4bc871b7407e6d4fe09cc7cb`.

Scope: isolated development. Do not install, publish, or merge until native Factorio QA and user in-game acceptance.

## Current ownership (stage 4 + targeted bugfixes)

- `control.lua`: only event registration, update scheduling, lifecycle/GUI dispatch, plus per-tick orchestration; has no direct power measurement or circuit slot writer.
- `power_meter.lua`: **single owner of power-measurement computation**, cumulative input/output comparison, Factorio statistics/direct fallbacks, scaling, rounding, physical GUI snapshot, and diagnostics. Resets cumulative baselines on disable and on truly unavailable electric network; immediately writes zero power and clears mod-generated MK2 feedback on electric disconnect, while preserving X factor. Delegates native slot writing to `circuit_slots.lua`.
- `electric_statistics.lua`: cumulative network statistics, filtered prototype counts and maximum power estimates.
- `electric_direct.lua`: direct local-network power measurement for MK1.
- `filter_baseline.lua`: MK2 cumulative statistics baseline reset when the effective filter selection changes.
- `mk2_filters.lua`: MK2 item-signal-to-energy-prototype selection with feedback compensation; **read-only** for circuit slots.
- `circuit_slots.lua`: **sole writer for all native combinator slots** (factor X in slot 1, power slots 2-5 and MK2 feedback slots 6+ in the FIRST native section). Clears feedback and previous echo counts if BOTH external red/green circuit networks are absent, even when get_signals reports the combinator's own signals. Preserves all additional player-created native sections and their settings.
- `meter_sensors.lua`: single owner for hidden meter lookup/creation, circuit wire attachment, sensor-status lamp and disposal.
- `combinator_state.lua`: active combinator allocation/cleanup, persistent registration mapping, existing-entity reconstruction and delegation to sensor/circuit/ALT modules. If either hidden meter cannot be obtained, `meter_sensors.dispose` cleans up any partially created meter before abandoning the state.
- `power_rounding.lua`: rounding and half-boundary handling; must preserve X5 750 kW -> 8 nearest.
- `power_units.lua`: display unit conversions and factor labels.
- `energy_gui.lua`: overview, settings and diagnostics presentation; reads circuit slots, never writes measured signals.
- `alt_units.lua`: one ALT label per active combinator.

## Correction: MK2 filter feedback without a circuit wire (14 November 2026)

The user correctly flagged our earlier screenshot interpretation. The vanilla GUI caption "Nicht verbunden" means the constant combinator has no red/green CIRCUIT network; it is not the hidden electric sensor network. Previously, the MK2 filter-feedback slots could remain set while disconnected because the mod relied on get_signals() alone, which can include the combinator's own outputs. A missing power pole is not equivalent to missing a red/green circuit wire.

## ECMOD9: three-mode MK2 (15 November 2026)

User-accepted specification (REGISTER_WORK / WORK-033): three distinct MK2 modes with **AUTO** as the default for new and existing MK2 entities.

- **auto**: Detect effective external red/green circuit energy-building signals (Factorio item signals whose placed entity consumes or generates electric energy). No cable, empty cable, solely invalid/virtual signals or entirely self-generated feedback => **nil** filters, meaning the entire electric network is measured by MK1's direct/full-grid path. At least one valid signal => prototype-filtered consumption/production and maxima. Feedback excludes the combinator's own circuit output and duplicate prototype names.
- **all**: Explicit full-grid measurement; ignore incoming circuit filter signals, including an active wired sender.
- **manual**: User chooses electrical entity prototypes in the dedicated MK2 Settings tab using a Factorio entity choose-element picker; named prototypes are stored per MK2 `unit_number` (up to 32, deduplicated/sorted), without needing a circuit wire. Empty manual list => entire grid. Manual selection does not emit misleading auto feedback.
- Persist in `storage.mk2_modes`; `mk2_modes.lua` owns this table and validations; `mk2_filters.lua` determines filters, `power_meter.lua` remains the sole physical measurement owner, `circuit_slots.lua` the sole output writer. `combinator_state.lua` allocates and removes settings, preserves across `on_configuration_changed` state rebuild; cloning copies distinct tables. UI operations dispatched by `control.lua`.
- GUI diagnostic displays configured mode and *effective* full-grid vs. filtered mode. Localization added in DE/EN/RU; original Factor X, rounding settings and ALT behavior remain.
- Wire/filter-mode changes use the existing `filter_baseline.lua` rebase logic to avoid cross-selection spikes.
- Reuse prototype names and current version 1.2.14 **only for the isolated experimental test archive**. This is **not** a published release or upgrade of the stable main branch.

## Candidate Factorio 2.1 API improvements (not yet enabled)

`LuaFlowStatistics.get_current_input_sample(id)` and `.get_current_output_sample(id)` return samples for the **current tick**, not an average of a configured five-tick update interval. Evaluate against cumulative deltas for radar, solar, accumulators, shortages, mixed filters, filter transitions and saves before replacing MK2. New quality-specific statistics require explicit quality/normalization semantics. `LuaElectricNetwork` and `LuaElectricSubNetwork` are available for more precise network introspection. See https://lua-api.factorio.com/latest/classes/LuaFlowStatistics.html.
