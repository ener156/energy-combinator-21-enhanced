Version: 1.2.10
Date: 13.11.2026
  Features:
    - Edit each of the four circuit rounding modes directly in the Energy Combinator
      Settings tab. The values remain shared by the map and with normal Mod Settings.
    - Show a map-wide ALT-unit toggle beside the rounding selectors.
    - Add the electric-network and satisfaction-sensor IDs, measurement source,
      estimated Tier 2 filter count and enabled state to the Diagnostics tab.
    - Keep ALT unit labels above native circuit icons and scale longer units down
      to reduce overlap with nearby combinators.
  Compatibility:
    - Preserve existing circuit-slot factor X, global rounding defaults,
      entity prototypes, signal names, stored sensors and original native GUI.
    - In multiplayer, only admins can change the shared rounding and ALT settings
      from the new GUI; other players can inspect the settings.
    - Development candidate: test on dedicated Factorio 2.1 runner before installation.

Version: 1.2.9
Date: 12.11.2026
  Features:
    - Normal clicking an Energy Combinator opens a dedicated tabbed overview instead of
      the native constant combinator interface.
    - Overview shows four physical power readings and selected scaling unit; settings
      offer the existing signal-factor editor and current map rounding rules.
    - Diagnostics show electric-network sensor ID and stage-specific filter information.
    - ALT mode shows the selected signal unit above each combinator (W, 10 W, 100 W,
      kW, 10 kW, 100 kW, MW, GW and further SI prefixes).
    - The ALT label can be disabled in map mod settings.
  Compatibility:
    - Existing Ctrl+Shift+E shortcut and the new GUI button still open the original
      combinator interface for advanced circuit inspection.
    - Scaling remains authoritative in circuit slot 1, with existing output signals,
      map-wide rounding choices and 5-tick update default unchanged.
    - No changes to entity prototypes, hidden electricity sensors or Tier 2 filters.
    - Built as a candidate only, pending isolated Factorio GUI and ALT visual tests.

Version: 1.2.8
Date: 12.11.2026
  Features:
    - Add four independent map-wide rounding choices under Settings > Mod settings > Map:
      current consumption, current production, maximum consumption and maximum production.
    - Each signal supports nearest integer, round up or round down.
    - Changes take effect on the next regular signal update without restarting Factorio.
  Compatibility:
    - Defaults preserve the previous behavior: current consumption/production round to
      nearest, maximum consumption rounds up, maximum production rounds down.
    - Keep precision-aware boundary corrections for the up/down modes and the high-X
      maximum-consumption fix; no entity IDs, signal IDs or scaling settings are changed.
    - Existing saves and Tier 2 filters retain their previous behavior by default.

Version: 1.2.7
Date: 10.11.2026
  Bugfixes:
    - Prevent the maximum-consumption signal from incorrectly becoming zero at very high scaling
      factors (for example, 1 MW at X=15 now gives 1).
    - Normalize tiny floating-point overshoots at whole-number boundaries (e.g. 100.00000000000001
      gives 100, not 101); genuine fractional demand still rounds upward.
    - The existing mathematically rounded current measurements and the conservative maximum-
      production rounding are unchanged.
  Compatibility:
    - Retain all user-selected scaling values and the 5-tick default update interval.
    - No changes to Tier 2 filters, electric-network statistics or entity prototype calculations.
